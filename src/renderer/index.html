    Setup

    Connect your workspace to ChatGPT.

    Follow these six steps once. The pictures show where to click. Start with Core; desktop control is optional.

    1. Pick a folder to share

      Choose the folder you want ChatGPT to work in. You can add more folders later.

      None yet

    2. Create a tunnel

      1. Open Tunnels and click “Create tunnel” at the top right of the page. Enter a name and description.
      2. At the bottom, select your workspace under ChatGPT workspaces. Choose the same workspace you use in ChatGPT. You can search by name or workspace ID.
      3. Keep your existing organization selected. Selecting an organization alone does not make the tunnel appear in ChatGPT.
      4. Click Create, copy the new Tunnel ID and paste it below.
      Desktop control optional

      Screen and mouse/keyboard control are a separate connector, so they need a second tunnel. Create another one and paste its ID here. Leave it empty to keep desktop control off in ChatGPT.

    3. Create an API key

      1. Open API keys and click “Create new secret key” at the top right of the page.
      2. Leave Owned by set to You. Select your project, for example Default project. A name is optional. An expiration date is required.
      3. Under Permissions, choose Restricted. Scroll down to Tunnels and enable Read and Use. Leave everything else at None.
      4. Create the key, copy it and paste it below. You can only copy the secret once.

    4. Start the tunnel

      Click Connect and wait for Connected. The tunnel must be running before you can add the plugin in ChatGPT.

      Leave it running while you use the connector. It stays available when you close the window.

    5. Add it in ChatGPT

      A · Enable Developer mode

      In ChatGPT, open Settings → Security and login and turn on Developer mode.

      B · Create the Core plugin

      1. Open the ChatGPT Plugins page using the button above. Click + at the top right to open New Plugin.
      2. Copy the name and description from the Core card below.
      4. Under Authentication, choose No Auth. Do not paste your API key here.
      5. Read and accept the notice, then click Create. Keep the tunnel running while ChatGPT connects.
      Before you start: choose “Allow all actions”

      In ChatGPT, open Settings → Plugins, select this plugin, and set its action permissions to Allow all actions. Repeat for the Desktop plugin if you added it.

      This lets ChatGPT use the plugin without asking for each action. Otherwise, approval prompts can pause Goal, Loop and agent tasks. Your folder and tool permissions in this app still apply.

    6. Add the Chrome extension

      1. Open chrome://extensions.
      2. Turn on Developer mode at the top right.
      3. Click Open extension folder below and copy the folder path from the file manager’s address bar.
      4. In Chrome, click Load unpacked, paste the copied folder path and select that folder.

      The extension pairs with this app automatically — there is no code to type.

      Required for sub-agents: the companion extension must be loaded and connected in ChatGPT. Without it, Chat On Steroids cannot identify, open or coordinate worker chats.

    Workers & recovery

    Chrome tab badges Goal and Loop titles say Working only with live activity; otherwise they say Waiting. One-off is finite work. Attention means a verified failure or sign-in problem.
    GGoal LLoop WWorker 1One-off !Attention
    Sub-agent workers Requires the Chrome extension to be loaded and connected. This sets the most worker chats one run may open. max
    Active Loop chats Keep up to this many top-level Loop conversations working or recovering. Worker chats use their own per-task limit. In limited mode this is also the global automatic-chat ceiling. target
    Rotation batch In Rotation mode, run this many top-level Loop chats at once. Each chat still chooses its own useful worker count up to its saved/global limit. chats
    Rotation window After this long, the active batch stops receiving new automatic work, finishes in-flight turns/tools, then yields to the next batch. minutes
    New-chat priority slots Temporarily let this many newly started chats run above the normal Rotation batch. Their current turn finishes, then a Loop joins the front of the regular queue. slots
    Rate-limit cooldown Used only in limited mode. Existing chats keep running while new automatic openings pause for 15 seconds. seconds
    Sleeping worker runtime Release safely owned terminal processes after this idle period while preserving the worker chat and history. minutes
